# So I am trying to make a portfolio project -- its basically a syllabus maker

So I am trying to make a portfolio project -- its basically a syllabus maker. It ingests your GoodReads data and it turns it into topics that you may be an expert of (we're pretending a professor is the user) and it takes that knowledge and creates potential topics for a syllabus. The cartographer agent does this work, and then outputs potential topics. Then we have a multi-agent researcher agent that will start developing a syllabus based on research on the topic you click. Since this is only for a portfolio project I wnat this to look a lot cooler - like more modern Arabic/Islamic geometric design or calligraphy. And I want the topics to maybe be more smartly shaped.
